# Instagram Reels — TP React

Lancer : `npm run dev`.

Prototype visuel statique : trois Reels, scroll vertical avec CSS, boutons décoratifs.
Les composants utilisent des props et un tableau statique, sans hooks ni événements JavaScript.

Remplacer `public/videos/reel1.mp4`, `reel2.mp4` et `reel3.mp4` par vos vidéos.
Les deux premières utilisent la même vidéo de démonstration.
Modifier les textes et compteurs dans `src/App.jsx`, et le style dans `src/App.css`.

Vidéos de démonstration : fleurs [MDN](https://interactive-examples.mdn.mozilla.net/media/cc0-videos/flower.mp4) ; bande-annonce [Sintel, Blender Foundation](https://media.w3.org/2010/05/sintel/trailer.mp4).
